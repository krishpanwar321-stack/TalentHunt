##  Features

- Responsive, mobile-first UI ✨  
- Reusable components built with React  
- Custom hooks for efficient state management  
- Tailwind CSS for highly modular, performant styling  
- Next.js framework for SSR or static generation  
- Easy configuration and deployment with Tailwind + PostCSS  

---

##  Tech Stack

- **Framework**: Next.js (React + TypeScript)  
- **Styling**: Tailwind CSS, PostCSS  
- **Language**: TypeScript  
- **Package Manager**: pnpm  
- **Utilities**: Custom hooks in `hooks/`, utilities in `lib/`

## Getting Started

### Prerequisites

* Node.js (v16+ recommended)
* pnpm (for package management)

### Installation

```bash
# Clone the repository
git clone https://github.com/ZaidSheikh04/talent-hunt-website.git
cd talent-hunt-website

# Install dependencies
pnpm install

# Run locally (development)
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view.

To build and run production:

```bash
pnpm build
pnpm start
```
